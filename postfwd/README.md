# postfwd setup on DMS Postfix

By default, rate-limiting is disabled on OpenPanel servers. To enable it, edit `/usr/local/mail/openmail/postfwd/postfwd.cf` and configure the desired limits for each IP address, email address, or domain.

## Enable

```bash
opencli email-server postfwd enable
```

This adds `check_policy_service inet:postfwd:10040` in front of the mailserver's current `smtpd_recipient_restrictions` and sets `smtpd_policy_service_default_action = DUNNO` (emails still go out if postfwd is down), in `docker-data/dms/config/postfix-main.cf` and live with `postconf` + `postfix reload`. No mailserver restart is needed. Per-account rules from the plans' hourly limit are generated with `opencli email-ratelimit --all-users`.

## Disable

```bash
opencli email-server postfwd disable
```

## Customization

Examples:
```bash
# Limit per IP
id=limit_ip ; protocol_state==RCPT
                action=rate(client_address/300/3600/450 4.7.1 sorry, max 300 requests per hour)

# Limit per email
id=limit_user_hour ; sender=~.+@.+ ; protocol_state==RCPT
                action=rate(sender/500/3600/450 4.7.1 sorry, max 500 emails per user per hour)

# Limit per domain
id=limit_domain_generic ; sender=~.+@.+ ; protocol_state==RCPT
                action=rate(sender_domain/2000/3600/450 4.7.1 sorry, max 2000 emails per domain per hour)

# Limit entire server (protocol_state is RCPT for every request, so they all share one counter)
id=limit_server_hour ; protocol_state==RCPT
                action=rate(protocol_state/10000/3600/450 4.7.1 sorry, max 10000 emails per server per hour)

# Limit per OpenPanel account, as generated by opencli email-ratelimit: tag each domain with the account, the shared rule id makes all its domains count together
id=limit_stefan_example_com ; sender=~.+@example.com$ ; protocol_state==RCPT
                action=set(op_account=stefan)
id=limit_stefan_rate ; sender=~.+@example.com$ ; protocol_state==RCPT
                action=rate(op_account/100/3600/450 4.7.1 sorry, OpenPanel account reached limit of 100 emails per hour)
```

`rate()` counts per value of the request attribute it names (`client_address`, `sender`, `sender_domain`, ...) and per rule id. A fixed text like `rate(stefan_ratelimit/...)` is not an attribute, so it never counts.
